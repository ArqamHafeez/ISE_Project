# Small Store Barcode Tool

A C++17 command-line program for generating and reading six-digit Code 39
barcodes. Barcode generation and BMP image handling use code written for this
project; no barcode-generation library or database is required.

## Features

- Accepts exactly six digits, with a first digit from `1` to `9`.
- Shows a compact ASCII barcode preview in the terminal.
- Saves the barcode as an uncompressed 24-bit BMP image.
- Reads horizontal Code 39 barcodes from uncompressed 24-bit or 32-bit BMP
  images. The reader is intended for barcodes generated by this program.

## Build

With CMake:

```text
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

Or compile directly with a C++17 compiler:

```text
g++ -std=c++17 -Wall -Wextra -Wpedantic -Isrc src/main.cpp src/barcode.cpp src/image.cpp -o store_barcode
```

On Windows, run `store_barcode.exe`; on other systems, run `./store_barcode`.

## Use

The program starts with a numbered menu with ANSI colors in terminals that
support them (such as the VS Code terminal and Windows Terminal).
Choose **Generate a barcode**, enter a valid number, and accept the suggested
filename or enter a BMP path. Choose **Read a barcode from a BMP image** and
enter the image path to decode it. Use `0` to exit.

The barcode encoder, image format handling, and CLI are separate source
modules, so future inventory and sales features can call the barcode functions
without depending on the menu.
